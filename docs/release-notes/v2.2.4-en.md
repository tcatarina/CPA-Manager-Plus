# CPA Manager Plus v2.2.4

[中文](https://github.com/tcatarina/CPA-Manager-Plus/blob/v2.2.4/docs/release-notes/v2.2.4-zh.md)

## Upstream stability fixes

Integrates the stable changes from upstream v1.14.3 while preserving the fork's GLM credential details, reset cards, Codex reset-credit refresh, and release infrastructure.

- Improve CPA v8 visual configuration reads and writes, including client API keys, canonical-path precedence, historical aliases, and YAML merge keys.
- Preserve derived pricing, monitoring, and aggregate state during transient SQLite contention. Keep hard failures blocking unsafe archive cleanup.
- Add Safari favicon and iOS touch-icon support, embedded fallback routes, and release artifact checks.

## Compatibility and upgrade

No credential migration is required. Existing fork configuration and release numbering remain unchanged.

Native packages target Linux and macOS on amd64 and arm64. Windows packages are not published.
