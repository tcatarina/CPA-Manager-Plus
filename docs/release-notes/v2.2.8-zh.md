## 概述

同步上游 v1.14.8 和 v1.14.9，包含依赖安全维护、凭据与配额展示修复。保留本分支的 GLM 支持、更新仓库配置，以及 Linux/macOS 原生安装包。

## 修复

- 同一范围内的后台刷新或临时请求失败时，保留凭据历史、配额使用量、统计分析与模型价格表。
- 凭据身份变更时清除旧凭据的历史证据，但不丢弃其他行的数据。
- 使用事件提供商信息消除监控来源歧义，并保留配置的上游名称。
- 展示更多 Antigravity 配额窗口，区分已确认的零使用量与未知、过期数据。
- 改进 xAI 订阅计划识别；订阅查询失败时仍保留已观测到的配额。

## 安全与构建维护

- 引入上游修复后的 Go/Node 工具链，以及应用、文档和构建依赖。
- 在 CI 中强制执行 npm 依赖审计及跨平台 Go 漏洞检查。
- 将验证时发现的额外风险依赖 Zod 更新至 4.6.7；该依赖仅用于开发工具。

## 验证

- 前端 4,525 项测试通过；类型检查、生产构建、文档构建通过。
- Manager Server 2,848 项 Go 测试通过；vet 和漏洞检查通过。
- 验证时 npm audit 报告零已知漏洞。
- 使用生产前端构建、独立 SQLite 数据库及本地隔离 CPA 进行运行时冒烟测试：初始化与登录、页面导航、凭据刷新与布局切换、GLM 抽屉显示、用量导入和读取、重启持久化与未授权请求拒绝均通过，浏览器没有未捕获异常。
- NixOS 主机缺少测试夹具硬编码的 `/bin/rm` 和 `/bin/mv`，因此两项未修改的安装器测试未通过；合并提交在 GitHub Linux runner 上的 PR Check 已成功。

## 升级说明

不需要数据库迁移、重新创建凭据或改写配置。本次发布准备不部署 VPS。源码构建需要 Go 1.26.10，以及满足仓库 engines 约束的 Node.js 版本。
