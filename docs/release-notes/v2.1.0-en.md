# CPA Manager Plus v2.1.0

[中文](https://github.com/tcatarina/CPA-Manager-Plus/blob/v2.1.0/docs/release-notes/v2.1.0-zh.md)

## GLM credential details

The GLM eye-icon action in AI Providers now opens the same shared detail drawer used by Credential Management, with Overview, Quota, Settings, Models, and Diagnostics tabs.

- Show the Z.AI plan, five-hour and weekly allowances, recent requests, recorded usage, and diagnostics for the selected API key.
- Edit configuration-backed credential settings without creating duplicate auth files. Weight and proxy settings apply to the selected key; routing, headers, retries, and model mappings are provider-wide.
- Add or remove configured models, edit aliases, and discover upstream models. Preserve sibling credentials and advanced configuration fields during updates.
- List GLM reset cards and redeem a selected card after confirmation. Validate upstream application responses and reuse the saved request ID when a redemption outcome is uncertain.
- Remove duplicate unknown-scope quota snapshot cards. Missing quota boundaries remain unknown rather than producing fabricated forecasts.

## Fork release links

Dashboard CPAMP version links now point to `tcatarina/CPA-Manager-Plus`. CLIProxyAPI release links are unchanged.

## Compatibility and upgrade

No database migration or credential migration is required. Existing GLM keys remain in CPA's OpenAI-compatible provider configuration. GLM quota, discovery, and reset-card operations use CPA's existing management `api-call` endpoint and runtime auth indexes.

Reset cards are consumed upstream. Closing the browser session loses the tab-scoped recovery record, so resolve an uncertain redemption in the same session before starting another reset.

Native packages target Linux and macOS on amd64 and arm64. Windows packages are not published.
