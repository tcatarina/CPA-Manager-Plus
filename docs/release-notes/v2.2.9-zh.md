## 概述

同步上游 v1.14.10，保留本分支的 GLM 支持、更新仓库、版本编号和 Linux/macOS 安装包。

## 变更

- 在表格与卡片视图中置顶关注的凭据；置顶仅保存在当前浏览器，并遵循现有筛选条件。
- 根据 CPA 版本处理 OAuth 模型排除优先级，包括 v8.0.33 及以后版本的凭据级覆盖，同时保留 GLM 提供商模型编辑。
- 修复同页 URL 更新与凭据搜索、筛选、布局和详情状态的同步。
- 显示插件声明的类型化默认配置，且不在无关保存操作中写入默认值。
- 派生投影缺失或过期时，从完整原始事件恢复历史价格查询。
- 仅为经过管理员认证的只读请求转发 CPA v8 API-key 分组接口；其他 v8 路径与写入仍被阻止。
- 应分支维护者要求，移除 PR 检查和定时工作流中的 npm 依赖审计及 Go 漏洞扫描。测试、构建、lint、发布来源和产物校验保持启用。

## 验证

- 前端 4,569 项、仓库脚本 259 项和 Go 2,867 项测试通过。
- 类型检查、生产前端构建、文档构建、Go vet、演示隔离与网页图标检查通过。ESLint 无错误，存在七项已有警告。
- 新增 GLM 提供商配置与模型编辑的合并回归测试。
- 本版本执行自动化测试与构建，未重新进行交互式本地 CPAMP 运行时冒烟测试。

## 升级说明

不需要数据库迁移、重新创建凭据或改写配置。依赖扫描不再是自动 CI 门禁；本版本不声明依赖不存在已知风险。本次不部署 VPS。
