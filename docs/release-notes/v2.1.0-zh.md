## GLM 凭证详情

AI 提供商中的 GLM 详情按钮现在使用与凭证管理相同的共用抽屉，包含概览、额度、设置、模型和诊断五个页签。

- 显示所选 API 密钥的 Z.AI 套餐、五小时及每周额度、近期请求、记录用量和诊断。
- 直接编辑提供商配置，无需建立重复认证文件。权重与代理属于所选密钥；路由、请求头、重试和模型映射由提供商的所有密钥共用。
- 支持模型发现、添加或移除映射及编辑别名，保存时保留其他密钥和高级配置字段。
- 列出 GLM 重置卡，确认后兑换。验证上游业务响应，结果不确定时使用已保存的相同请求 ID 重试。
- 移除未知模型范围造成的重复额度卡片。不完整的周期边界保持未知，不生成虚构预测。

## 分支版本链接

仪表盘中的 CPAMP 版本链接现在指向 `tcatarina/CPA-Manager-Plus`，CLIProxyAPI 版本链接保持不变。

## 升级与兼容性

无需数据库或凭证迁移。GLM 密钥继续保存在 CPA 的 OpenAI 兼容提供商配置中，额度、模型发现和重置操作使用已有管理 API 与运行时认证索引。

兑换重置卡会消耗上游卡片。恢复记录限于当前浏览器会话；结果不确定时，请在同一会话内完成重试，勿另行发起重置。

原生包支持 Linux 与 macOS 的 amd64、arm64，不发布 Windows 包。
