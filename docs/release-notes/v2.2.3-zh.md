## 凭证管理列表中的 Codex 重置额度

在凭证管理列表中刷新额度时，Codex 用量窗口会更新，但不会加载账号的重置额度。只有进入账号详情抽屉并在其中刷新后，重置额度才会出现。

- 当已观测到重置额度数量、但尚未观测到额度明细时，Codex 额度刷新现在会一并加载重置额度明细。
- 列表与详情抽屉使用同一新鲜度规则，因此两者都能恢复过期或缺失的重置额度。
- 批量刷新与单行刷新按钮行为一致。

## 升级与兼容性

不涉及接口、数据库或凭证变更，重置额度的查询、兑换与重试行为保持不变。

原生包支持 Linux 与 macOS 的 amd64、arm64，不发布 Windows 包。
