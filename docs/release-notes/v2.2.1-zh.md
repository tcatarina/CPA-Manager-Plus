## GLM 重置卡排版

额度页签中的 GLM 重置卡以无间距的行内文本渲染，窗口到期时间与兑换按钮文字相互紧贴。现改为与该页签中 Codex 重置额度卡片一致的行布局。

- 窗口名称、卡片标题与到期时间分行显示并保持统一间距，不再连成一段。
- 兑换按钮在卡片内右对齐，多张卡片之间增加垂直间距。
- 已过期或不可用的卡片保持原有的禁用行为。

## 升级与兼容性

仅排版变更。不涉及接口、数据库或凭证变更，重置卡的列表、确认、兑换与重试恢复行为完全不变。

原生包支持 Linux 与 macOS 的 amd64、arm64，不发布 Windows 包。
