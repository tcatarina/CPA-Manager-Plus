# CPA Manager Plus v2.2.9

> [中文 ->](https://github.com/tcatarina/CPA-Manager-Plus/blob/v2.2.9/docs/release-notes/v2.2.9-zh.md)

## Overview

Sync upstream v1.14.10 while preserving the fork's GLM support, updater repository, version numbering, and Linux/macOS packages.

## Changes

- Pin watched credentials above other matching results in table and card views. Pins remain browser-local and respect existing filters.
- Respect version-dependent OAuth model-exclusion precedence, including credential overrides on CPA v8.0.33 and later, without changing GLM provider model editing.
- Keep same-page URL changes, credential search, filters, layout, and detail state synchronized.
- Display typed plugin configuration defaults without writing them during unrelated saves.
- Recover historical pricing reads from intact raw events when derived projections are missing or stale.
- Forward authenticated-admin, read-only CPA v8 API-key group requests. Other v8 routes and writes remain blocked.
- Remove automated npm dependency audits and Go vulnerability-scan jobs from PR checks and the scheduled workflow, at the fork operator's request. Tests, builds, lint, release provenance, and artifact checks remain enabled.

## Validation

- 4,569 frontend tests, 259 repository tests, and 2,867 Go tests passed.
- Type checking, production web build, documentation build, Go vet, demo isolation, and web icon checks passed. ESLint reported no errors and seven existing warnings.
- Added merge regressions for GLM provider configuration and model editing.
- This sync was validated through automated checks and builds; no new interactive local CPAMP runtime smoke test was performed for v2.2.9.

## Upgrade Notes

No database migration, credential recreation, or configuration rewrite is required. Dependency scanners are no longer an automated CI gate; this release does not claim that dependencies have no known advisories. No VPS deployment is included.
