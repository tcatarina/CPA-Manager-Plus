## 同步上游

集成上游 v1.14.5 的稳定变更，同时保留本分支的 GLM 凭证详情、重置卡和发布流程。

- 支持无密钥（keyless）的 OpenAI 兼容上游，包括无 API Key 凭证的正确认证路由、代理处理与健康标签。
- 保留重置额度证据来源并支持安全恢复，统一汇总与专用重置证据，避免被取代的重试再次触发过期错误提示。
- 调整额度冷却处理，并补充 keyless 编辑器测试覆盖。

## 升级与兼容性

无需凭证迁移，GLM 凭证抽屉、额度窗口与重置卡保持不变。

原生包支持 Linux 与 macOS 的 amd64、arm64，不发布 Windows 包。
