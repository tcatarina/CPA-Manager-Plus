# CPA Manager Plus v2.2.6

[中文](https://github.com/tcatarina/CPA-Manager-Plus/blob/v2.2.6/docs/release-notes/v2.2.6-zh.md)

## Upstream sync

Integrates the stable changes from upstream v1.14.5 while preserving the fork's GLM credential details, reset cards, and release infrastructure.

- Support keyless OpenAI-compatible upstreams, including correct auth routing, proxy handling, and health labels for credentials without an API key.
- Preserve reset-credit evidence provenance with safe recovery, reconcile summary and dedicated reset evidence, and stop a superseded retry from resurfacing a stale rejection.
- Adjust quota-cooldown handling and add keyless editor test coverage.

## Compatibility and upgrade

No credential migration is required. The GLM credential drawer, quota windows, and reset cards are unchanged.

Native packages target Linux and macOS on amd64 and arm64. Windows packages are not published.
