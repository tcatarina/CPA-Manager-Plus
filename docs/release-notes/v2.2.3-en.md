# CPA Manager Plus v2.2.3

[中文](https://github.com/tcatarina/CPA-Manager-Plus/blob/v2.2.3/docs/release-notes/v2.2.3-zh.md)

## Codex reset credits in Credential Manager

Refreshing quota from the Credential Manager list updated the Codex windows but did not load the account's reset credits. The credit details were only fetched after opening the account detail drawer and refreshing there.

- A Codex quota refresh now loads reset credit details when the count is available but the details have not been observed yet.
- The list and the detail drawer use the same freshness rule, so both recover stale or missing credits.
- Batch refresh behaves the same as the per-row refresh button.

## Compatibility and upgrade

No API, database, or credential changes. Reset-credit listing, redemption, and retry behaviour are unchanged.

Native packages target Linux and macOS on amd64 and arm64. Windows packages are not published.
