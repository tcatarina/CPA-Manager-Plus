# CPA Manager Plus v2.2.1

[中文](https://github.com/tcatarina/CPA-Manager-Plus/blob/v2.2.1/docs/release-notes/v2.2.1-zh.md)

## GLM reset card layout

The GLM reset card rows on the Quota tab rendered as unspaced inline text, so the window expiry ran directly into the redeem button label. Each card now uses the same row layout as the Codex reset-credits card on that tab.

- Window label, card title, and expiry are stacked with a consistent gap instead of running together.
- The redeem button is right-aligned in the card, and multiple cards are separated vertically.
- Expired or blocked cards keep their existing disabled behaviour.

## Compatibility and upgrade

Layout-only change. No API, database, or credential changes, and no behaviour change to reset-card listing, confirmation, redemption, or retry recovery.

Native packages target Linux and macOS on amd64 and arm64. Windows packages are not published.
