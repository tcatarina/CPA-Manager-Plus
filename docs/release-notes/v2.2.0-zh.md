## 同步上游

同步上游 v1.14.2 发布的稳定修复。

- **CPA v8 客户端 API Key**：同时读取 v8 引入的 `access.api-keys` 结构与原有结构。此前 v8 配置可能表现为没有客户端密钥。
- **用量清理后重建定价**：历史用量维护会删除归档记录。模型定价改为从保留的事件重建，而不是标记为不可恢复，使模型价格与监控同步恢复收敛。
- **账号历史降级**：某个账号的成本无法重建时，该账号的请求数、Token 和成功率仍然可用，仅成本列显示为未知。

定价恢复按账号隔离，单个不可恢复的账号不再阻塞其他所有账号的重建。覆盖率错误与校验器系统错误分别归类，SQLite 繁忙争用不再丢弃派生状态。

## 分支行为

与 v2.1.0 保持一致：

- GLM 凭证详情继续使用共用五页抽屉，包含额度、设置、模型、诊断和重置卡兑换。
- 仪表盘 CPAMP 版本链接仍指向 `tcatarina/CPA-Manager-Plus`，CLIProxyAPI 版本链接不变。

## 升级与兼容性

无需数据库或凭证迁移，GLM 密钥继续保存在 CPA 的 OpenAI 兼容提供商配置中。

需要 CPA v7.3.4 或更高版本。原生包支持 Linux 与 macOS 的 amd64、arm64，不发布 Windows 包。
