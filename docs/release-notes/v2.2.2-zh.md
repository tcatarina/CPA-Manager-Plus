## 凭证详情页签间距

GLM 重置卡区块与上方额度窗口卡片紧贴在一起。抽屉页签面板自身没有布局，而其父级容器使用 12px 网格，因此一个页签内渲染多个区块时彼此之间没有间距。

- 页签面板现在同样是 12px 网格，与抽屉主体容器保持一致。
- 同一页签内的区块之间保持统一间距。

Codex 凭证抽屉每个页签只渲染一个区块，其布局不受影响。

## 升级与兼容性

仅排版变更，不涉及接口、数据库或凭证变更。

原生包支持 Linux 与 macOS 的 amd64、arm64，不发布 Windows 包。
