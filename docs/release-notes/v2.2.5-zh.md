## 同步上游

集成上游 v1.14.4 的稳定变更，同时保留本分支的 GLM 凭证详情、重置卡、Codex 重置额度刷新和发布流程。

- 更新 xAI Grok 客户端标识。chat-proxy 会以 HTTP 426 拒绝低于 1.0.13 的 Grok CLI 版本。
- 将探测认证与 CPA 运行时对齐，补齐 Claude OAuth 探测的代理与 URL 一致性，并保护 Anthropic beta 探测语义。
- 分类用量恢复查询错误并恢复快照回退，在无法证明定价覆盖率时隔离汇总比较。

## 升级与兼容性

无需凭证迁移，GLM 额度、重置卡以及分支更新通道保持不变。

原生包支持 Linux 与 macOS 的 amd64、arm64，不发布 Windows 包。
