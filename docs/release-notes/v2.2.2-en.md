# CPA Manager Plus v2.2.2

[中文](https://github.com/tcatarina/CPA-Manager-Plus/blob/v2.2.2/docs/release-notes/v2.2.2-zh.md)

## Account detail tab spacing

The GLM reset cards section sat flush against the quota windows above it. The drawer tab panel had no layout, while its parent shell used a 12px grid, so a tab rendering more than one section had no spacing between them.

- The tab panel is now a 12px grid, matching the drawer body shell.
- Sections inside a tab are separated consistently.

The Codex detail drawer renders a single section per tab, so its layout is unchanged.

## Compatibility and upgrade

Layout-only change. No API, database, or credential changes.

Native packages target Linux and macOS on amd64 and arm64. Windows packages are not published.
