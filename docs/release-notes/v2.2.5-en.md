# CPA Manager Plus v2.2.5

[中文](https://github.com/tcatarina/CPA-Manager-Plus/blob/v2.2.5/docs/release-notes/v2.2.5-zh.md)

## Upstream sync

Integrates the stable changes from upstream v1.14.4 while preserving the fork's GLM credential details, reset cards, Codex reset-credit refresh, and release infrastructure.

- Update the xAI Grok client identity. Chat-proxy rejects Grok CLI versions older than 1.0.13 with HTTP 426.
- Complete Claude OAuth probe parity by aligning probe authentication with the CPA runtime, plus proxy and URL parity fixes and protected Anthropic beta probe semantics.
- Classify usage recovery query errors and restore the snapshot fallback, and isolate summary comparison when pricing coverage cannot be proven.

## Compatibility and upgrade

No credential migration is required. GLM quota, reset cards, and the fork's update channel are unchanged.

Native packages target Linux and macOS on amd64 and arm64. Windows packages are not published.
