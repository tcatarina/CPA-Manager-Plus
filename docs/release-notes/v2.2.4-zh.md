## 上游稳定性修复

集成上游 v1.14.3 的稳定变更，同时保留本分支的 GLM 凭证详情、重置卡、Codex 重置额度刷新和发布流程。

- 完善 CPA v8 可视化配置的读取和写入，包括客户端 API Key、规范路径优先级、历史别名与 YAML 合并键。
- SQLite 短暂争用时保留定价、监控和聚合派生状态；实际硬故障仍阻止不安全的归档清理。
- 增加 Safari 网站图标与 iOS 触摸图标支持、内嵌回退路由及发布产物检查。

## 升级与兼容性

无需凭证迁移，现有分支配置与版本编号规则保持不变。

原生包支持 Linux 与 macOS 的 amd64、arm64，不发布 Windows 包。
